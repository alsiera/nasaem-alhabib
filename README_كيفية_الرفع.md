# نسائم الحبيب — دليل الرفع (استضافة أونلاين)

هذا الفولدر (`site/`) جاهزٌ للرفع كموقع ثابت. كل الروابط **نسبية**، فيشتغل أونلاين وأوفلاين، والضغط يفتح في **نفس التاب**.

## الملفات
- `index.html` — صفحة الفهرس (الصفحة الرئيسية)
- `01-ibrahim.html` — من إبراهيم إلى الميلاد
- `02-mawlid.html` — من الميلاد إلى البعثة
- `03-boycott.html` — مساومة قريش وصحيفة المقاطعة
- `extra-mawlid-nasha.html` — المولد والنشأة (الرحيق المختوم)

> ⚠️ لا تغيّر أسماء الملفات — الروابط بينها معتمدة على الأسماء دي.

---

## أسهل طريقة (بدون حساب أو أوامر): Netlify Drop
1. افتح: **app.netlify.com/drop**
2. اسحب فولدر `site` كله وارميه في الصفحة.
3. هيديك لينك فورًا (زي `random-name.netlify.app`). خلاص، شغّال.
   - الرئيسية هي `index.html` تلقائيًّا.

## GitHub Pages (مجاني)
1. اعمل Repository جديد على github.com (مثلًا `naseem-alhabib`)، واخليه **Public**.
2. اضغط **Add file → Upload files**، وارفع محتويات فولدر `site` (مش الفولدر نفسه — الملفات اللي جواه).
3. **Settings → Pages → Branch: main / (root) → Save**.
4. بعد دقيقة يطلع لينك: `https://<username>.github.io/naseem-alhabib/`

### بديل بالأوامر (لو مركّب git + gh)
```bash
cd site
git init && git add . && git commit -m "نسائم الحبيب"
gh repo create naseem-alhabib --public --source=. --push
gh api repos/{owner}/naseem-alhabib/pages -f source[branch]=main -f source[path]=/
```

## تعديل النص (محميّ بـ PIN)
- في كل صفحة، زرار **✎** تحت على الشمال.
- اضغطه → أدخل الرمز → يتفعّل «وضع التعديل»، وتقدر تعدّل النصوص مباشرة.
- **رمز الدخول الحالي: `1445`** — غيّره في كل ملف: افتح الملف ودوّر على السطر `var PIN = "1445";`.
- أزرار الشريط:
  - **حفظ** → يحفظ تعديلاتك في *هذا المتصفح* (يظهر لك إنت بس).
  - **تنزيل الصفحة** → ينزّل نسخة HTML بتعديلاتك مدموجة. **ارفعها مكان الملف القديم** على الاستضافة عشان التعديل يظهر **للجميع**.
  - **تراجع** → يمسح تعديلاتك ويرجّع الأصل.

> ملاحظة أمان: الـPIN حماية خفيفة فقط (الرمز موجود داخل كود الصفحة، فأي حد يفتح «مصدر الصفحة» ممكن يشوفه). كفاية لمنع التعديل العرضي، لكنه **مش تأمين حقيقي**. التأمين الحقيقي محتاج سيرفر/تسجيل دخول (خارج نطاق الموقع الثابت).
